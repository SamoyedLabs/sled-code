The React thread strip translates OpenBot 0.60.0, commit 0c7753fa622c38419939cd230657f40e5883d098, primarily packages/ui/src/features/conversation/threads/ThreadTabs.tsx, SidePanel.tsx and styles/side-panel.css. See OPENBOT-LICENSE.

OpenbotThreadTabs.tsx retains the source tab hierarchy, measured selected fill, rename overlay, compact and minimal header modes, contextual actions, keyboard focus, overflow fades and model-picker fitting. openbotThreadTabDrag.ts translates the 4px drag threshold, neighboring shifts, FLIP reorder, 40px edge autoscroll at a maximum of 12px per frame, cross-row drag preview and reverse docking. OpenbotSideThreadTabs.tsx renders the side header, including source thread chrome, reordering and return to chat. Both use source styles within .openbot-react. React lifecycle bindings dispose observers, animation frames and window listeners.

The host supplies the real task list, selected task identity and guarded rename/archive/restore/delete callbacks. The original required strip props remain compatible. Optional layout/onLayoutChange carry the source open/active/side model; onMoveToSide enables docking. useOpenbotThreadTabLayout persists that model by the caller's JSON.stringify([environmentId, hostId, agentId]) scope. Local tab closure and docking do not mutate host tasks.

The host mounts OpenbotSideThreadTabs directly beneath .conversation-panel, alongside the conversation body, so the source docking boundary can be measured. Its props are threads, selectedId, onSelect, onClose, onMove and onMoveToChat, with optional maximized, children and actions. The host owns the matching side conversation, its selection and panel state.

tasks/SourceNewThreadDraft.tsx uses the existing React port of the source conversation composer and dictation. It sends task.start only after explicit Send, preserves the exact start text and clientMessageId in session storage scoped to environment/host/agent, and passes only a confirmed matching-agent task ID to onCreated. A failed or interrupted response retains the attempt for explicit retry; remount does not send. It accepts initialDraft/onDraftChange, onCancel and onOutcomePendingChange for workspace composition. Attachments remain unavailable on the frozen task.start bridge.

The focused model tests cover exclusive docking ownership, source close-to-left selection, scoped storage corruption, unequal-width drag thresholds and retained start identities. Native client interaction and motion verification has not been run in this source-only pass.
