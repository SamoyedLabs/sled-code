These React leaves translate OpenBot 0.60.0, commit `0c7753fa622c38419939cd230657f40e5883d098`. The upstream license is [OPENBOT-LICENSE](../OPENBOT-LICENSE).

The reference is `packages/ui/src/features/marketplace` (Marketplace, Nav, Browse, Cards, Parts, Skills, Agents, SkillPage and AgentPage), with the controller from `src/renderer/src/features/settings/MarketplaceModal.tsx`. `marketplace.css` retains source declarations inside `.openbot-react`; keyframes are at stylesheet scope so React portals and browser view transitions can resolve them. `marketplace-adapter.css` supplies the workspace mount geometry. Solid signals and Kobalte bindings are replaced by React state and existing React controls; catalog reads, permissions, pinned installations, and durable template adoption use the Sled contracts and guarded commands.

`article-gradient.ts` preserves `packages/brand/src/article-gradient.ts`. `SkillGradient.tsx` adapts the source shader lifecycle to React with the exact `@paper-design/shaders@0.0.80` dependency, including visibility, reduced motion, disposal and context failure behavior. Marketplace Apps are supplied by the separately ported `marketplace-apps` leaves; no catalog records are synthesized by this shell.

This is a source port, not a declaration of complete parity. The original skill authoring/revision flow, original agent-install dialog selection/drag behavior, and skill trial conversation entry are not fully exposed by these leaves. The guarded installation and adoption adapters remain authoritative. Presence of source CSS does not imply an unmounted source feature is implemented.
