These React leaves translate OpenBot 0.60.0, commit `0c7753fa622c38419939cd230657f40e5883d098`, under [OPENBOT-LICENSE](../OPENBOT-LICENSE).

App navigation comes from `src/renderer/src/features/settings/SettingsModal.tsx`; General, Notifications and Voice come from the adjacent source tabs. Profile, Updates and Mobile Connect use `packages/ui/src/features/settings`. Host settings remain a separate shell, with MCP from `src/renderer/src/features/servers/ServerMcpPanel.tsx`. Bot settings come from `packages/ui/src/features/conversation/AgentSettingsPanel.tsx`, AgentFolders, AgentInstructionsView and BackupModels, together with the renderer AgentSettingsPanel controller. `SettingsPanel.tsx` retains the source components' header, link group, row and scroll structure. The avatar editor and normalization preserve `packages/brand/src/bloub-avatar.ts` and `packages/ui/src/avatar-image.ts`.

Routines use `src/renderer/src/features/conversation/AgentRoutinesSettings.tsx` and the UI RoutineSchedulePicker, RoutineDateField (yearly branch), RoutineWeekdayPicker, RoutineTimeField, RoutineHoursWindowPicker, RoutineRunHistory, RoutineWebhookTrigger, RoutineWebhookEndpoint, RoutineWebhookEvents and RoutineResultDestinationField. The schedule draft conversion is copied from `packages/team-client/src/routine-schedule-draft.ts`; clock conversion comes from the UI schedule draft module; scalar filter parsing comes from `packages/contracts/src/event-filter-value.ts`. English routine messages are copied from `packages/i18n/src/messages/en/routine.ts`. The frozen Team API intentionally excludes native one-time schedules, delivery history and redelivery; the UI does not manufacture those capabilities.

Source CSS is scoped to `.openbot-react`, with keyframes lifted to stylesheet scope. Solid lifecycle/state and Kobalte controls are replaced with React/Base UI and the shared source menu motion. The existing T3 preference store owns applicable app preferences. Host operations use guarded commands, preserve the selected host session, and retain expected-version checks where the host provides them. Existing MCP arguments and credentials remain on the host: source form fields explicitly replace opaque values through a partial patch, while untouched fields are preserved.

App/native capabilities are supplied by the parent composition. Source folders use the guarded host browser; backup model selection preserves saved account identifiers but does not yet expose the full source account picker. Native-only runtime settings and source mobile platform artwork require their corresponding adapters. These leaves do not establish complete visual or native runtime parity by themselves.
