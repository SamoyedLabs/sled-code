# Marketplace Apps source port

Pinned source: OpenBot 0.60.0, commit `0c7753fa622c38419939cd230657f40e5883d098`. License: [OPENBOT-LICENSE](../OPENBOT-LICENSE).

`plugin-catalog.ts` preserves all 31 shipped listings from `src/renderer/src/features/settings/marketplace-plugin-catalog.ts`, including names, categories, icon URLs, server transports, commands, authentication flows, prompts, and public links. Catalog install counts are shipped metadata, not host state. `plugin-model.ts`, `mcp-connect-flows.ts`, `mcp-accounts.ts`, and `relay-callback.ts` translate the source matching, credential assembly, account fragment, and callback-query rules.

`PluginAppPage.tsx` ports `packages/ui/src/features/marketplace/MarketplaceAppPage.tsx`, including the source detail header, TryCard/SkillGradient requests, information, connections/accounts, and disconnect confirmation. The surrounding Marketplace shell owns grouping, navigation, search, and categories. `AppConnectDialog.tsx` ports `McpConnectShell`, `McpKeyDialog`, and the joined-host local-app boundary. `SourceMcpRelay.tsx` follows `web-client/web-mcp-relay.ts`, renders the shared source `McpSignInPage` controls, and opens no browser until the user chooses Open.

`BuiltinApps.tsx`, `DiscordAccess.tsx`, `BrandMarks.tsx`, and their copied CSS translate `GitHubConnectorPanel`, `SlackIntegrationPanel` (including Discord), `TelegramIntegrationPanel`, `ChannelParts`, `IntegrationLayout`, and the source brand paths. They retain device sign-in status/confirmation, repository filtering, channel connect/pause/reconnect/disconnect, orchestrator setup, Discord role access, and read/error states. The existing source VaultConnectorEnvironment supplies 1Password and Bitwarden details. Unmatched saved MCP entries and Add app mount the shared ServerMcpPanel source editor.

The React boundary is `useSourceMarketplaceApps({environmentId, hostId, hostName?, onPrompt?})`. It returns `apps`, optional `appsError`, `appsOverlay`, and `onAddApp` for the existing Marketplace shell. Its owner is keyed by environment, host, and retained session. Every command rechecks permission and the original session. Host configuration notifications refresh connection state. The hook reads existing guarded MCP operations and uses the server-only catalog projection for exact identities; saved arguments, environment variables, headers, account addresses, and credentials remain private. Reconnect patches merge only the supplied credential fields on the host. A new configuration is saved only after a successful explicit test or sign-in. A failed/unknown save does not silently retry. Account creation is gated by `mcp-accounts-v1`; rename eligibility comes from projected account IDs, never a guessed sanitized URL.

Source API boundaries are explicit: WhatsApp pairing, allowed senders, and phone groups have no frozen joined-host route in this source version, so its detail page explains that host-local requirement. Local desktop MCP setup and macOS Automation prompts likewise stay on the host. The frozen messaging orchestrator request accepts platform/workspace only; model selection is omitted exactly as the source does when no model-choice callback is supplied. The TryCard is enabled when the workspace supplies its optional real prompt callback. No fake connection data or native IPC is substituted.

Validation: scoped source lint; web package typecheck; focused source identity, account URL, credential-byte preservation, callback-query, workflow geometry/schedule, task draft, calendar, and thread-layout tests. Runtime review is owned by the parent integration task.
