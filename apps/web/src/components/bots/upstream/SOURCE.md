The scoped CSS and React components in this directory are translations of OpenBot 0.60.0, commit 0c7753fa622c38419939cd230657f40e5883d098. See OPENBOT-LICENSE (PolyForm Noncommercial 1.0.0).

openbot-tokens.css copies packages/brand/src/tokens.css and tokens-light.css with root selectors scoped to .openbot-react. openbot-shell-source.css retains the relevant source rules and their order from src/renderer/src/styles/app-shell.css, features/window/page-rail.css, features/sidebar/sidebar-views.css, features/conversation/styles/header-layout.css and styles/sliding-tabs.css. openbot-react.css adapts these classes to the T3 React composition. OpenbotSlidingTabs.tsx replaces the Solid/Kobalte binding with React DOM measurement and T3 observeResize, retaining source pill geometry/timing.

This is a source port in progress. Source features not yet exposed through this React composition must not be inferred from the presence of their CSS.

This source-port batch includes the original avatar engine/controller (under ../avatar), action-menu and tooltip motion, sidebar folder/drag helpers, rich composer and streaming/selection components, and group conversation/panel components. Existing T3 RPC/controllers retain authority and upload identities. The ready-attachment reorder UI is an adapter addition; it is not present in the upstream attachment row.

The React composition now includes source task/workflow/calendar pages, provider and model selection, Usage, Marketplace, global search, Files/Memory/storage, settings, browser chrome, thread layout and selection-instruction actions. Account and catalog operations use the host-scoped bridge. Full parity is not established: native-only integrations, People typing/custom photos and every real-account workflow are not covered by the current composition or acceptance. Do not infer support merely from imported source CSS.

FileSelectionPreview.css and ../BotFilePreview translate FilePreviewPanel/MarkdownFilePreview header and text geometry; transport and streaming large-file/media fallback stay in T3 AttachmentFilePreview through optional presentation slots. botSelectionModel retains the pinned file quote serializer, line selection and selected-instruction parser. The pinned syntax highlighter is ported in conversation/codeHighlighting.ts, SourceCodeBlock and SourceFileText using @speed-highlight/core 1.2.24. Canonical quote references open guarded original message/file identities, with anchored message reads and passage highlighting. The server negotiates the upstream installed-skills capability so request/response codecs retain semantic tags rather than expanding away their identities. iOS renders the same references through its native Markdown adapter; full native passage highlighting remains open.

People/direct conversation source is translated in SidebarPeopleSection, SourcePersonAvatar and SourceDirectConversation. DirectProtocol maps the original membership-checking HTTP facade into the existing host-scoped RPCs, with typed public projection and payload-free message invalidation. People order is local per environment/host. End anchoring, the 100-row static threshold and virtual history use the pinned @tanstack/virtual-core 3.19.7, with T3 observeResize for owned measurements. Unconfirmed drafts retain the original clientMessageId; retries are explicit and never automatically transmitted. The source People section stays hidden when no other enabled member exists.

This does not establish full visual/interaction parity. People typing, custom person photos, the source scroll rail/count animation, a native iOS People screen, custom group reader/picture data, native-only integrations and remaining account/provider/remote variants remain open. Desktop v17 now has actual message-passage and file-passage click/highlight captures after the earlier Computer Use timeouts. iOS launch was previously blocked by another Device recording and has not been reverified in this batch. Focused browser/component tests and packaged RPC checks are distinct from mounted native acceptance.
